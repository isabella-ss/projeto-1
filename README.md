## 🧑‍💻 Sobre Mim
Olá me chamo Isabella, Sou estudante de Engenharia de Software. Este repositório foi estruturado utilizando metodologias de controle de versão (Git/GitHub) e segurança da informação, com o suporte estratégico da inteligência artificial.

---

## 🎯 Objetivo 
O Objetivo deste repositorio é documentar, centralizar e manter a organização de projetos acadêmicos e pessoais de Eng. de Software.

## 🛡️ Gestão & Segurança do Hub
Para cumprir os requisitos de governança do desafio, a estrutura conta com:
* **Controle de Acesso:** Repositório configurado para auditoria e compartilhamento seguro.
* **Segurança de Credenciais:** Implementação rigorosa de arquivo `.gitignore` para mascarar chaves de API e variáveis de ambiente sensíveis.
* **Mensagens Padronizadas:** Histórico de Commits seguindo boas práticas (Conventional Commits).

---

## 📂 Projetos Implantados

Abaixo estão alguns projetos centralizados neste hub. 

* `projetos-academicos/` - Quaisquer projetos feitos durante a graduação, posteriormente atualzido e filtrado por disciplina
* `projetos-pessoais/` - Projetos experimentais, pessoais e até projetos de aprendizagem
